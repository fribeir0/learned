	Git init  > Inicia um repositorio na pasta

	Git pull > atualiza o repo no git local
	Git merge > junta duas branches para atualizar oq foi alterado
	Git rebase master > atualiza a base de uma branch para a branch master ou outra 
	Git commit -m “Mudança xxx” = faz um commit no repo de mudança de tal arquivo

	Git mv <arquivo> = usado para avisar paro o rep que moveu algo
